# Wheel-E - VESC Package
Wheel-E is a VESC Package for electric mini-bikes with a wheelie mode. The package is a fork of Refloat used in self-balancing skateboards.

Status as of 13.04.2026: Some code implemented. Compiles. Not tested. Bike not yet fabricated.

## Code
### Implemented:
* Implement a "NORMAL" state when not wheelieing
* Remove foot pad sensors 
* Implement 3-wire brake (hall sensor)
### Not yet started:
* Change the IU to display a mini-bike 

## Hardware
* Spintend UBox Lite 100v 100A
* Pint motor w. stock tire
* 14s7p 50s battery pack
